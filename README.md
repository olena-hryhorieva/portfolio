# Olena Hryhorieva - Portfolio

Public portfolio website for Olena Hryhorieva, Furniture & Object Concept Designer.

The site presents selected furniture, lighting, and human-centered object concepts, including hand sketches, an introductory Blender study, and implemented pieces. A separate fashion-styling practice is acknowledged as visual background and shared directly on request.

Live site: [olena-hryhorieva.github.io/portfolio](https://olena-hryhorieva.github.io/portfolio/)

## Local development

```text
npm install
npm run dev
```

## Production build

```text
npm run build
```

The static GitHub Pages output is written to `docs/`.
